# تشغيل أداة فحص ملفات IL2CPP

## الملفات المطلوبة

من نفس تثبيت Wrestling Empire 1.8.0:
- `global-metadata.dat`
- `libil2cpp.so`

## ماذا تفعل الأداة؟

الملف `inspect_il2cpp_inputs.py` يستخدم مكتبات Python القياسية فقط. لا يغيّر الملفات الأصلية، وينشئ:
- `input_summary.json`: أحجام الملفات ومعلومات رأس ELF الأساسية.
- `metadata_string_candidates.csv`: نصوص ASCII ذات صلة محتملة مع **مواضعها داخل ملف metadata**.

## تشغيلها

بعد وضع الملفين في مجلد واحد مع السكربت، افتح الطرفية في ذلك المجلد وشغّل:

```bash
python3 inspect_il2cpp_inputs.py global-metadata.dat libil2cpp.so --out il2cpp-report
```

يمكن نقل مجلد `il2cpp-report` الناتج لمراجعته أو إرفاقه.

## تنبيه مهم

هذه أداة فرز أولي وليست محلّل IL2CPP كاملًا. موضع النص داخل الملف ليس عنوان دالة. لا تستخرج الأداة MethodDefinition أو توقيعات الدوال ولا تربطها بعناوين native. لا يمكن استنتاج معادلات الضرر أو سلوك AI من هذه النتائج وحدها.

## على Android

قد لا يكون تشغيل Python والملفات الكبيرة مريحًا على الهاتف. إذا لم تتوفر بيئة Python، يمكن تنفيذ الخطوة على جهاز أو بيئة Linux. لا ترفع ملفات اللعبة إلى مستودع عام لمجرد تشغيل الأداة؛ احتفظ بها محليًا، وشارك فقط تقارير الفحص التي لا تحتوي على بيانات خاصة.
